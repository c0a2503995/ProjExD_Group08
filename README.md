# こうかとん脱出大作戦

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1
* 必要なものがあれば追記してください（非推奨）

## ゲームの概要
* 主人公キャラクターコウカトン（こうかとん）をキーボード操作により脱出させるゲームで，．．．
* 参考URL：[Dungeon Escape](https://store.steampowered.com/app/454100/Dungeon_Escape/?l=japanese&curator_clanid=29451349)

## ゲームの遊び方
* 矢印キーでコウカトンを操作し，スペースキー押下でジャンプする
* コウカトンが罠を避けて脱出する

## ゲームの実装
### 共通基本機能
* 背景画像と主人公キャラクターの描画
* 物理演算（重力・ジャンプ・衝突判定）と各種ギミック

### 分担追加機能
#### stage6（担当：山口）： stage6の障害物とギミック
* 上昇気流（進行妨害機能）
    * プレイヤーが上昇気流範囲内に入ると, 上方向に浮かせる. また, 空中ジャンプを回復する
    * マップ上に`^`を配置することで, 上昇気流が発生する
