# こうかとん脱出大作戦

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1
* 必要なものがあれば追記してください（非推奨）

## ゲームの概要
* 主人公キャラクター江華トン（こうかとん）をキーボード操作により脱出させるゲームで，．．．
* 参考URL：[Dungeon Escape](https://store.steampowered.com/app/454100/Dungeon_Escape/?l=japanese&curator_clanid=29451349)

## ゲームの遊び方
* 矢印キーで江華トンを操作し，スペースキー押下でジャンプする
* 江華トンが罠を避けて脱出する

## ゲームの実装
### 共通基本機能
* 背景画像と主人公キャラクターの描画

### 分担追加機能
stage5:高瀬
* **スライム床（減速トラップ機能）**
  * マップ上に `M` を配置することで設置される液体トラップ。
  * プレイヤーが触れている間、横移動速度が通常の40%に低下し、ジャンプや移動のタイミング調整を難しくするギミック。
