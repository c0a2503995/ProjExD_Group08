# からあげくん脱出大作戦

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 主人公キャラクターからあげくんをキーボード操作により脱出させるゲームで，．．．
* 参考URL：[Dungeon Escape](https://store.steampowered.com/app/454100/Dungeon_Escape/?l=japanese&curator_clanid=29451349)

## ゲームの遊び方
* 矢印キーでからあげくんを操作し，スペースキー押下でジャンプする
* からあげくんが罠を避けて脱出する
* 主人公キャラクター「からあげくん」をキーボード操作により脱出させる2Dアクションゲームである。
* ステージ内に設置された罠や敵を避けながら、鍵を取得し、出口を目指して進んでいく。
* ジャンプや二段ジャンプなどのアクションを活用し、さまざまな障害物を乗り越えてステージのクリアを目指す。
* 水中エリアではSPACEキーを押すことで泳ぐことができる。
* 参考URL：[Dungeon Escape](https://store.steampowered.com/app/454100/Dungeon_Escape/?l=japanese&curator_clanid=29451349)


## ゲームの実装

### 共通基本機能
* 背景画像と主人公キャラクターの描画
* 物理演算（重力・ジャンプ・衝突判定）と各種ギミック

### 分担追加機能
#### stage1（担当　髙松）
* プレイヤーを追従する敵（チェイサー）
  動き:近づくまで眠っていて起きたあとはずっと追ってきます。
  動く速度はプレイヤーより遅く壁をすり抜けます。

#### stage3 (担当　本橋)
* Stage 3 水中移動機能：水中オブジェクトの中に入ったとき、通常時とは異なる物理挙動に切り替え、水中を泳いで移動できる機能。
  * マップ上の「W」で指定された場所を水中エリアとして判定する。
  * 水中ではSPACEキーを押すことで上方向に泳ぐことができる。
  * 水中専用の重力や移動速度、落下速度の上限を設定し、通常時とは異なる移動を可能にする。
  * 水の抵抗を再現するため、速度を減衰させる処理を追加する。
  * 水中にいる間は通常時のジャンプ処理とは異なる水中専用の移動処理を行う。
  * 水中エリアを半透明の青色で描画し、プレイヤーが水中にいる場合は画面全体にも青色のフィルターを表示する。

#### stage4(担当　的野)
  * ステージギミックとして滑る床（氷）を追加

#### stage5（担当　高瀬）
* スライム床（減速トラップ機能）
  * マップ上に `M` を配置することで設置される液体トラップ。
  * プレイヤーが触れている間、横移動速度が通常の40%に低下し、ジャンプや移動のタイミング調整を難しくするギミック。
  
#### stage6（担当　山口）
* 上昇気流（進行妨害機能）
    * プレイヤーが上昇気流範囲内に入ると, 上方向に浮かせる. また, 空中ジャンプを回復する
    * マップ上に`^`を配置することで, 上昇気流が発生する

### メモ
* キーボード入力による主人公キャラクターの左右移動
* ジャンプや二段ジャンプなどの移動処理
* 重力や地形との衝突判定
* 敵キャラクターやトラップの配置と当たり判定
* 鍵の取得や扉の開閉、出口によるステージクリア処理
* ステージごとのマップ情報に基づいた地形やオブジェクトの描画
* 水中にいるかどうかを判定し、通常時と水中で物理挙動を切り替える構成にしている。
* 水中での重力や移動速度などは定数として管理し、調整しやすくしている。
